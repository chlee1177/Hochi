# 스페이스 머셔너리 — Godot 2D PC 게임

Godot 4.6에서 `project.godot`를 열고 F5로 실행하세요. 다키스트 던전에서 영감을 얻은 스트레스·진형·원정과 우주 용병단 운영을 조합한 독자적인 초기 프로토타입입니다. 원작 이미지·음악·캐릭터는 사용하지 않습니다. 전투 화면은 직접 그린 임시 2D 도형입니다.

## 플레이

용병 4명으로 출격합니다. 행동할 용병과 적을 선택해 공격/방어/회복 버튼을 누르세요. 모든 생존 용병이 행동하면 적 차례가 자동 진행됩니다. 왼쪽 두 명인 전열은 공격받을 확률이 높고 후열은 공격력이 낮습니다. 스트레스 100인 용병은 공격력이 감소합니다. 의무병의 회복량이 더 높고, 회복은 살아 있는 가장 부상당한 아군에게 적용됩니다.

적을 모두 쓰러뜨리면 크레딧을 받고 다음 임무로 넘어갑니다. 기지에서 크레딧으로 전원 치료·스트레스 회복, 진형 교대가 가능합니다. 전멸하면 새 캠페인을 시작할 수 있습니다. 전투 밖에서 저장/불러오기 버튼을 사용할 수 있으며 저장 위치는 Godot의 `user://campaign.json`입니다.

## 검증

`godot --headless --path . --script test_campaign.gd`

클라우드에서는 쓰기 가능한 XDG 캐시·설정 경로를 지정해야 합니다. 저장소 루트 README를 참고하세요.

PC 실행 파일 내보내기는 Godot의 Windows export templates 설치 후 진행하는 별도 단계입니다. 현재 Windows 게임 EXE는 생성하지 않았습니다.

후속 후보: 함선 업그레이드, 용병 고용·특성, 탐사 지도, 전리품, 함선 전투, 스토리 이벤트, 실제 스프라이트·음악. 이 기능들은 현재 구현 범위에 포함되지 않습니다.
